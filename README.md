# 지적클래스

강사가 문제를 출제하면 학생들이 휴대폰이나 노트북에서 닉네임으로 참여하고 답을 제출하는 수업용 퀴즈입니다. 지번과 필지 경계를 표현한 지적도 배경과 지적학 예제 문제 3개를 넣었습니다.

## 온라인 수업

배포된 강사 화면에서 강사 접속 키 또는 사이트를 만든 ChatGPT 계정으로 로그인합니다. 첫 화면에 참여 QR과 수업 코드, 참여 학생 수와 현재 문항의 제출 학생 수가 표시됩니다. **참여 링크 복사**로 같은 주소를 공유할 수 있습니다. 온라인 수업의 문제와 답안은 사이트 데이터베이스에 저장됩니다.

온라인 버전은 `node scripts/build-site.mjs`로 빌드합니다. Sites에 `TEACHER_EMAIL`, `TEACHER_KEY`, `TEACHER_SESSION_SECRET`을 서버 전용 환경 변수로 설정하고 `.openai/hosting.json` 및 `drizzle/`을 함께 배포합니다. `TEACHER_SESSION_SECRET`은 세션 서명에 쓰는 별도의 무작위 값입니다.

Vercel에서는 `vercel.json`이 `public/`을 배포하고 `/api/` 요청을 기존 Sites 수업 서버에 연결합니다. 두 주소에서 동일한 강사 접속 키와 수업 기록을 사용합니다.

## 로컬 실행하기

1. Windows에서 [start-class.cmd](./start-class.cmd)를 실행합니다. 터미널에서는 `node server.js`로 실행할 수 있습니다. Node.js 18 이상이 필요하며 별도 패키지 설치는 없습니다.
2. 강사 컴퓨터에서 [강사 화면](http://localhost:3000)을 엽니다. 서버 실행 창은 수업이 끝날 때까지 열어 둡니다.
3. 학생 기기를 강사 컴퓨터와 같은 와이파이 또는 로컬 네트워크에 연결합니다. 강사 화면에서 **참여 링크 복사**를 눌러 학생들에게 공유합니다. 학생용 참여 링크에는 수업 코드가 미리 들어갑니다.

강사 화면의 **학생 화면 열기**로 강사 컴퓨터에서 직접 참여를 시험할 수 있습니다. 다른 기기에서 연결되지 않으면 링크의 주소가 `localhost` 또는 `127.0.0.1`인지, 학교 와이파이가 기기 간 통신을 허용하는지, Windows 방화벽이 해당 연결을 허용하는지 확인하세요.

## 수업 진행하기

- **새 문제 만들기**에서 문제를 저장합니다. 객관식은 보기 중 정답 하나를 지정하고, 단답형은 인정할 정답을 한 줄에 하나씩 입력합니다. 서술형에는 강사용 채점 기준을 입력할 수 있습니다. **교재 챕터**와 **교재 목차**를 입력하면 문항의 출제 범위를 함께 표시합니다.
- 학생이 모이면 **출제 화면 열기**를 누릅니다. **출제 범위**에서 전체, 기초학습, 교재 챕터 또는 세부 목차를 선택합니다. **다음 문제 열기**는 선택한 범위의 문항을 목록 순서로 출제합니다. 챕터와 목차를 선택하면 본 학습 문항이 출제됩니다. **문제 목록 보기**에서 같은 범위의 문항을 확인하고 직접 선택할 수 있습니다. **참여 QR**은 참여 화면을 다시 띄웁니다.
- 객관식과 단답형의 제한시간은 30초입니다. 서술형은 열기 전에 문항별 제한시간을 30초에서 15분 사이로 정합니다. 처음 설정하는 문항의 기본값은 2분이며, 이후 같은 문항을 열 때 지난 설정값이 표시됩니다. 참여 학생 전원이 제출하면 즉시 자동 마감하고, 미제출 학생이 있으면 제한시간이 끝날 때 자동 마감합니다. 강사는 **접수 마감**으로 직접 마감할 수도 있습니다. 강사가 **다음 문제 열기**를 누르면 다음 문항으로 넘어갑니다.
- 교실에서는 **발표 화면**을 사용합니다. 현재 출제한 문항과 교재 챕터, 제출 수가 표시되고 마감 후에는 세부 목차와 집계도 확인할 수 있습니다. 출제 범위, 문제 목록, 개별 서술형 답안은 강사용 화면에서 확인합니다. 학생 휴대폰에는 강사가 연 문항만 표시됩니다.
- 문제 접수를 마감한 뒤 **응답 기록 → 서술형 채점**에서 답안별로 정답·오답을 선택합니다. 해당 문항이 학생 화면에 표시되는 동안 자기 채점 결과가 갱신됩니다.
- **응답 기록**의 **엑셀 다운로드**는 문항별 최신 마감 집계와 객관식 보기별 선택 수를 `.xlsx`로 저장합니다. 서술형 채점을 마치면 전체 집계를 내려받을 수 있습니다. **새 수업 시작**은 문제 목록을 보존하고 수업 코드, 참여 학생, 제출 답안과 응답 기록을 초기화합니다.

서버는 수업 내용을 프로젝트 폴더의 `.quiz-state.json`에 기록합니다. `PORT`로 접속 포트, `QUIZ_STATE_FILE`로 저장 경로, `PUBLIC_URL`로 공유할 링크의 호스트를 지정할 수 있습니다. 강사 컴퓨터의 `localhost`에서는 자동 로그인됩니다. 다른 기기에서 강사 화면을 열 경우 서버 실행 창에 표시된 키를 입력하거나 `TEACHER_KEY`로 설정한 키를 사용합니다. `TEACHER_KEY`를 설정하면 `localhost`에서도 키가 필요합니다.
