# 지적클래스

강사가 문제를 출제하면 학생들이 휴대폰이나 노트북에서 닉네임으로 참여하고 답을 제출하는 수업용 퀴즈입니다. 지번과 필지 경계를 표현한 지적도 배경과 지적학 예제 문제 3개를 넣었습니다.

## 온라인 수업

배포된 강사 화면에서 강사 접속 키 또는 사이트를 만든 ChatGPT 계정으로 로그인합니다. **QR 코드**를 누르면 학생이 휴대폰 카메라로 찍어 들어올 수 있는 참여 화면을 띄웁니다. **참여 링크 복사**를 누르면 같은 주소를 공유할 수 있습니다. 온라인 수업의 문제와 답안은 사이트 데이터베이스에 저장됩니다.

온라인 버전은 `node scripts/build-site.mjs`로 빌드합니다. Sites에 `TEACHER_EMAIL`, `TEACHER_KEY`, `TEACHER_SESSION_SECRET`을 서버 전용 환경 변수로 설정하고 `.openai/hosting.json` 및 `drizzle/`을 함께 배포합니다. `TEACHER_SESSION_SECRET`은 세션 서명에 쓰는 별도의 무작위 값입니다.

Vercel에서는 `vercel.json`이 `public/`을 배포하고 `/api/` 요청을 기존 Sites 수업 서버에 연결합니다. 두 주소에서 동일한 강사 접속 키와 수업 기록을 사용합니다.

## 로컬 실행하기

1. Windows에서 [start-class.cmd](./start-class.cmd)를 실행합니다. 터미널에서는 `node server.js`로 실행할 수 있습니다. Node.js 18 이상이 필요하며 별도 패키지 설치는 없습니다.
2. 강사 컴퓨터에서 [강사 화면](http://localhost:3000)을 엽니다. 서버 실행 창은 수업이 끝날 때까지 열어 둡니다.
3. 학생 기기를 강사 컴퓨터와 같은 와이파이 또는 로컬 네트워크에 연결합니다. 강사 화면에서 **참여 링크 복사**를 눌러 학생들에게 공유합니다. 학생용 참여 링크에는 수업 코드가 미리 들어갑니다.

강사 화면의 **학생 화면 열기**로 강사 컴퓨터에서 직접 참여를 시험할 수 있습니다. 다른 기기에서 연결되지 않으면 링크의 주소가 `localhost` 또는 `127.0.0.1`인지, 학교 와이파이가 기기 간 통신을 허용하는지, Windows 방화벽이 해당 연결을 허용하는지 확인하세요.

## 수업 진행하기

- **새 문제 만들기**에서 문제와 정답을 저장합니다. 객관식은 선택지 2~4개 중 정답 하나를 지정합니다. 단답형은 인정할 정답을 한 줄에 하나씩 입력합니다. 단답형 채점은 유니코드 표기, 공백, 영문 대소문자를 정규화해 비교합니다.
- 문제 목록에서 문항을 선택하고 **문제 열기**를 누릅니다. 로컬 버전을 처음 실행하면 지적학 예제 객관식 1번 문제가 열려 있습니다.
- **응답 집계**에서 제출 수와 정답률을 확인합니다. 객관식은 보기별 선택 수가 표시됩니다. **접수 마감**을 누르면 학생은 자기 답안의 채점 결과를 볼 수 있습니다.
- 강의실 화면에 띄울 때는 **발표 화면**을 사용합니다. 접수 중에는 제출 수를 보여 주고, 마감하면 문항별 집계와 정답을 표시합니다.
- **응답 기록**에서 마감된 문항별 집계를 볼 수 있습니다. **엑셀 다운로드**는 문항별 최신 마감 집계와 객관식 보기별 선택 수를 `.xlsx`로 저장합니다. **새 수업 시작**은 문제 목록을 보존하고 수업 코드, 참여 학생, 제출 답안과 응답 기록을 초기화합니다.

서버는 수업 내용을 프로젝트 폴더의 `.quiz-state.json`에 기록합니다. `PORT`로 접속 포트, `QUIZ_STATE_FILE`로 저장 경로, `PUBLIC_URL`로 공유할 링크의 호스트를 지정할 수 있습니다. 강사 컴퓨터의 `localhost`에서는 자동 로그인됩니다. 다른 기기에서 강사 화면을 열 경우 서버 실행 창에 표시된 키를 입력하거나 `TEACHER_KEY`로 설정한 키를 사용합니다. `TEACHER_KEY`를 설정하면 `localhost`에서도 키가 필요합니다.
